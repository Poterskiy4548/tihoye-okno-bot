# Тихое окно — психолог-консультант

Telegram-бот для записи на консультации.  
Работает через SOCKS5-прокси (переменная `SOCKS5_PROXY`).

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Задайте переменную окружения `BOT_TOKEN` (токен от @BotFather)
3. Запустите: `python main.py`

## Переменные окружения
- `BOT_TOKEN` – токен бота
- `ADMIN_IDS` – твой telegram id
- `SOCKS5_PROXY` – адрес SOCKS5-прокси (например, `socks5://132.243.248.109:1080`)
